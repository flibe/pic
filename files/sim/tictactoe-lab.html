Tic-Tac-Toe Lab

The agent of the lesson plays X and learns from nothing but the result of its games. It keeps a table with one number per board, its estimate of the probability of winning from there, starts every entry at one half, moves ε-greedily and, after each greedy move, pulls the value of the board it left towards the value of the board it reached. Watch it play, make it play ten thousand games in a second, change ε and the learning rate, and then sit down against it.

What to notice

  • Learning is visible in a few hundred games. Against the opponent that blocks and wins when it can, the agent starts by losing most games; watch the green curve climb while the table fills. Press "10 000 games" to see where it settles.
  • Values change from the end of the game backwards. Step through the first games and the empty cells all read 0.50: a backup moves a value only towards the value of the next board, and in the first games every next board is still at 0.5. Only the last board before the result moves at first, towards 1 or 0; the board before it moves in a later game, once that line is played again, and so on. With these settings the opening values leave 0.50 after about 60 to 200 games, and after 500 the best opening is already valued near 0.85. This one-step propagation is the price of the temporal-difference rule, and it is what the longer backups of the next lessons speed up. Values that have moved are shown in blue when above 0.5 and in red when below.
  • ε = 0 is not a trap here, and it is worth seeing why. Forget all, set ε to zero and play ten thousand games against the sensible opponent: the greedy agent ends up winning more often than with ε = 0.1, about 85% of the games against 74%. The reason is the initial value 0.5: a board that leads to a loss is pulled towards 0, falls below the untried boards still at 0.5, and the greedy choice moves on to them. The optimistic start does the exploring, as the optimistic initial estimate does in the slot machine lab. The price shows in the table: the greedy agent meets about 1300 boards against 2100, so it knows less of the game and would be caught out by an opponent that plays differently.
  • ε is paid for during play. With a large ε the agent explores a lot, learns a wide table, and loses games it knew how to win, because one move in three is random. The learning curve and the playing strength are two different things: this is why ε is usually reduced as learning proceeds.
  • The learning rate decides how much the last game counts. With α close to one each value becomes the value of the next board, and the table jumps with every game; with a small α it settles slowly but smoothly. Against a random opponent the outcome of one game is mostly luck, and a small α is what averages the luck out.
  • What a draw is worth changes what the agent wants. With a draw worth 0, as in the lesson, the agent sees no difference between drawing and losing; against the perfect opponent, which it can never beat, nothing it learns raises its values above 0 and its play stays indifferent. Tick "a draw is worth 0.5" and it learns to force the draw instead.
  • Exploratory moves and backups. By default the value of a board is not updated when the agent leaves it with an exploratory move, because that move is not what its policy would do. Tick the box to back up anyway and compare: the values then also reflect what happens after random moves, which makes them estimates of the ε-greedy policy rather than of the greedy one.

The problem being solved

The tic-tac-toe of the lesson, section 1.5 of Sutton and Barto. The state is the board; the table holds V(s), the agent's estimate of its probability of winning from s, for every board it has met:

V(s) = 1 if X has won, 0 if O has won, 0 (or 0.5) for a draw, 0.5 at first for every other board

Before each move the agent considers the boards reachable with one X, reads their values, and with probability 1−ε moves to the one with the largest value (the greedy move, ties broken at random); with probability ε it moves at random (an exploratory move). After a greedy move, the board it left is backed up:

V(St) ← V(St) + α [ V(St+1) − V(St) ]

where St is the board after the agent's previous move and St+1 the board after the greedy move. When the game ends, the last board the agent produced is backed up towards the value of the final position, 1, 0 or the value of a draw. This is the temporal-difference rule of the lesson, old value ← old value + step · (target − old value), with a constant step α.

The opponent does not learn. "Sensibly" means: complete three in a row if possible, otherwise block the agent's three in a row, otherwise move at random. "Perfectly" is the minimax player, which never loses; against it the best the agent can do is to draw. The values shown in the empty cells are the current values of the boards the agent would reach by moving there; the highlighted cell is the move it chose.
